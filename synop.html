Station plot legend

Red = temperature (°C) · Green = dew point (°C)
Circle fill = cloud cover (oktas) · barb = wind (knots, half=5, full=10, pennant=50)
Symbol left of circle = present weather · top-right = MSLP/QNH shorthand (last 3 digits of tenths-hPa) — not raw hPa: "209" means 1020.9 hPa. Full value always in the tooltip.
Blue "F" badge = a TAF forecast is available — click the marker to view it.

Coverage note

SYNOP: ~135 UK WMO stations (03xxx block). METAR/TAF: ICAO-coded UK aerodromes, civil + military. These overlap at major airports but are otherwise distinct networks from each other and from the Met Office one-minute network (a separate page). METAR cloud cover is approximated from its FEW/SCT/BKN/OVC categories, not a true oktas count. TAF is a forecast, not an observation — shown as raw text on click, not decoded into the station plot. Precipitation is not decoded for either source.

Sources: SYNOP via Ogimet (WMO Global Telecommunication System). METAR/TAF via NOAA Aviation Weather Center.
